# Sline Demolition Website

Official website for Sline Demolition Ltd.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- App Router
- pnpm
- Vercel

## Development

Install dependencies:

```bash
pnpm install
```

Start the local development server:

```bash
pnpm dev
```

Open:

http://localhost:3000

## Build

Create a production build:

```bash
pnpm build
```

Run the production build locally:

```bash
pnpm start
```

## Deployment

The website source code is hosted on GitHub.

Production and preview deployments are handled through Vercel.

- Pushes to the main branch deploy the production site.
- Other branches and pull requests can generate preview deployments.

## Project Structure

```text
app/          Next.js routes and pages
components/   Reusable UI components
data/         Project and service data
public/       Images, icons, logo and other static assets
```
